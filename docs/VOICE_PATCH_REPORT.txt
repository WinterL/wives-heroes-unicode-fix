To the Wives Who Were Heroes — Voice patch report

Summary
Restore missing Japanese dialogue voices and history replay in the English,
Traditional Chinese, Simplified Chinese and Korean scenarios, using the Japanese
dialogue as the reference. Existing earlier Chinese translations are restored
where text was missing; no new dialogue is written. Japanese scenarios, audio,
artwork, the engine, executable and saves are unchanged. Original script
encoding, line endings and line counts are preserved.

Method and scope
Target: Steam build 25049578, base 0.26.6.22, Patch 1 1.26.6.12,
Patch 2 2.26.7.23. Other builds have not been checked.

Cross-reference each localized scenario with the Japanese dialogue: voice IDs,
their order, parameters, and the corresponding text/wait boundaries. Restore
disabled matching cues and correct obsolete or wrong references. Recover two
missing Chinese dialogue lines, including their waits, from the existing earlier
game archive. Repair one malformed Korean tag that stops scenario parsing.

The overlay contains 54 translated scenario scripts and 985 changed lines.
These totals include the opening Demon Queen fix. They are edit counts, not
counts of unique spoken lines. English: 3 files / 6 lines; Traditional Chinese:
5 / 8; Simplified Chinese: 5 / 8; Korean: 41 / 963.

Japanese-present voice cues were compared across all 249 scenario groups and
four translations. The patch leaves no missing expected static voice cues in
that comparison. Playback and history-replay dispatch were checked with the
game's parser; this is not a full-route playthrough or a listening test.

    preserving the surrounding Korean text (1 line).

Installation / removal
Close the game and place patch_3.xp3 beside yuusyatsuma.eXe. The voice fix is
independent of Apply.cmd and utf8hack. Keep patch_1.xp3 and patch_2.xp3.
If patch_3.xp3 already exists, keep a backup and check what it contains before
replacing it; this patch does not merge unrelated scenario mods.
Restart the game and replay the scene. Existing history entries are not updated.
To undo this overlay, close the game, remove or rename only this patch_3.xp3,
and restore any previous patch_3.xp3 you backed up. Restore.cmd handles the
separate startup/fullscreen fix, not this voice overlay.

Preserved differences
The extra Korean loop voice in 03_ap_201_12_ko.ks is retained. Unrelated
background-music/effect filename issues, narration-only pacing differences and
other text/layout differences are outside this voice patch.

This is an unofficial overlay for an existing game installation. Game scenario
content remains subject to its original rights; the project's MIT license for
original code and documentation does not relicense that content.
