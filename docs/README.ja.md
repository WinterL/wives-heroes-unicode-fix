# かつて勇者だった妻達へ — 起動・全画面・音声修正パッチ

[English](../README.md) · [繁體中文](README.zh-TW.md) · [简体中文](README.zh-CN.md) · 日本語 · [한국어](README.ko.md)

- **起動エラー**：ANSI → Unicode 変換エラーを修正します。現在のシステムロケールと UTF-8 設定を維持でき、日本語ロケールへの変更は不要です。
- **全画面にすると真っ黒になる問題**：高 DPI 環境での解像度の誤認識を修正し、デスクトップに合わせて縦横比を保って表示します。別のウィンドウへ切り替えて戻った後も操作できます。
- **音声とバックログ再生の欠落**：日本語シナリオと照合し、英語・繁体字中国語・簡体字中国語・韓国語シナリオの日本語音声とバックログ再生を修正します。

これは非公式パッチです。[Steam の公式説明](https://store.steampowered.com/app/4358140/)では日本語のシステムロケールが必要とされています。[公式トラブルシューティング](https://store.steampowered.com/news/app/4358140/view/717917724409331753?l=tchinese) · [DLsite](https://www.dlsite.com/maniax/work/=/product_id/RJ01464205.html)

## インストール

### 起動・全画面

1. [Apply.cmd](../Apply.cmd) をファイルページ右上のボタンでダウンロードします。[utf8hack v1.2.0](https://github.com/uyjulian/utf8hack/releases/tag/v1.2.0) の `utf8hack.intel32.clang.7z` をダウンロードし、`utf8hack.dll` を展開します。
2. Steam でゲームを右クリック → **管理 → ローカルファイルを閲覧**。開いたフォルダーに `Apply.cmd` と `utf8hack.dll` を置きます。
3. ゲームを終了して **Apply.cmd** をダブルクリックし、完了後に Steam から起動します。

### 音声・バックログ再生

1. ゲームを終了し、[patch_3.xp3](../patch_3.xp3) をファイルページ右上のボタンでダウンロードします。Steam でゲームを右クリック → **管理 → ローカルファイルを閲覧**。`yuusyatsuma.eXe` と同じフォルダーに置きます。
2. 既存の `patch_1.xp3` と `patch_2.xp3` は残してください。`patch_3.xp3` がすでにある場合は、ゲームフォルダー外にバックアップして出所を確認してから置き換えを判断してください。同名の別パッチとは競合する可能性があります。
3. Steam から再起動し、対象の場面に入り直してください。過去のバックログに欠けている再生リンクは自動では追加されません。

音声パッチは単独で導入できます。音声だけを修正する場合、`Apply.cmd` や `utf8hack.dll` は不要です。

## 仕組み

| ファイル | 変更内容 |
|---|---|
| `utf8hack.tpm` | `utf8hack.dll` をコピーし、エンジンがプラグインとして読み込む名前にします。 |
| `yuusyatsuma.cf` | `Shift_JIS`（CP932）でスクリプトを読み込み、全画面では現在のデスクトップ解像度に合わせて縦横比を保ち自動拡大・縮小します。16:9 以外の画面では黒帯が入ります。 |
| `yuusyatsuma.eXe` | `ＭＳ Ｐゴシック` を ASCII の `MS PGothic` に変更し、DPI-aware 宣言を追加して、文字コードエラーと全画面解像度の誤認識を防ぎます。 |
| `patch_3.xp3` | 54 本のシナリオを上書き読み込みし、音声命令・音声 ID・バックログ再生を修正します。繁体字・簡体字中国語で欠けていた字幕と待機も各 1 か所補います。 |

日本語シナリオの対応する台詞と音声命令を基準に照合しました。変更は 54 本のスクリプト、985 行であり、985 種類の台詞という意味ではありません。既存の日本語音声を使用し、新しい録音は追加していません。具体的な変更は[音声パッチ報告](VOICE_PATCH_REPORT.txt)をご覧ください。

## 検証範囲

**更新版との互換性（2026-10-29）：** Steam build **26287432** でも既存のダウンロードファイルを使用でき、再インストールは不要です。音声パッチが上書きする54本の元スクリプトに変更はありません。今回はファイル単位の検証であり、実機プレイの再検証は行っていません。[詳細](TESTING.md#steam-build-26287432-compatibility)。

Steam build **25049578**：本体 **0.26.6.22**、Patch 1 **1.26.6.12**、Patch 2 **2.26.7.23**。検証環境：Windows **11 Pro 25H2（26200.9457）、x64**、システムロケール **zh-TW**、コードページ **UTF-8（65001）**。画面 **3840×2160、拡大率 225%**。

通常の Steam 起動、ウィンドウのメインメニューと音楽、全画面表示、クリック、Alt+Tab を確認済みです。全編プレイ、セーブ／ロード、他の環境は未検証です。EXE／プラグインのハッシュ不一致は警告のみです。[テスト詳細](TESTING.md)

音声パッチは全シナリオの言語間比較を行い、元のエンジンのパーサーで音声・再生命令の呼び出しを検証しました。スクリプト段階の検証であり、全ルートの実機プレイや全台詞の試聴は行っていません。[範囲と変更内容](VOICE_PATCH_REPORT.txt)

## 復元とライセンス

起動・全画面の修正を戻すには、[Restore.cmd](../Restore.cmd) をゲームフォルダーに置き、ゲーム終了後に実行します。復元に成功するとバックアップが削除され、この 2 つの修正を再適用できます。`Restore.cmd` は音声パッチを削除しません。

音声パッチを戻すには、ゲームを終了し、本プロジェクトの `patch_3.xp3` だけを削除するか、`patch_3.xp3.disabled` に名前を変更します。以前の `patch_3.xp3` をバックアップしていた場合は復元してください。
