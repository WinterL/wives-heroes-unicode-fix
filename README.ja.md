# かつて勇者だった妻達へ：Unicode 起動修正

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

Windows Steam 版『かつて勇者だった妻達へ / To the Wives Who Were Heroes』用の**非公式・実験的な互換性パッチ**です。繁体字中国語のシステムロケールと UTF-8 コードページを維持したまま、吉里吉里 2 の ANSI → Unicode 変換による起動エラーに対処します。変更対象は3ファイルです。日本語ロケール、Locale Emulator、吉里吉里 Z への置き換えは不要です。

**確認済みの範囲：**元の起動エラーを通過し、ゲーム名の付いたウィンドウと初期設定ファイルが生成されました。メニュー描画、実際のプレイ、音声、セーブ／ロードは**未検証**です。[テスト記録](TESTING.md)もご確認ください。

ゲームのバージョンは、タイトル画面のスクリプトが参照するローカルのバージョン情報から確認しました。タイトル画面の画像を確認したという意味ではありません。ツールは [supported_versions.json](supported_versions.json) にある EXE と3つのアーカイブの SHA-256 を参考として照合します。不一致は警告のみで適用を続行し、`--force` は不要です。ただし、修正位置のフォント名バイト列は既知の状態と一致する必要があります。Windows 10、他のロケール、他ストア版は未検証です。OS が64ビットでも、ゲームは32ビットなので **32ビット版プラグイン**を使用してください。

## 初めての方向けの手順

1. ゲームを終了し、正規に入手した Steam 版がインストールされていることを確認します。[Windows 用 Python 3.10 以降](https://www.python.org/downloads/windows/)が必要です。インストール時に launcher／PATH オプションを含めてください。ツールは Python 3.13.12 で検証しました。
2. このリポジトリの **Code → Download ZIP** でダウンロードし、右クリックから**すべて展開**します。ZIP 内から直接実行しないでください。
3. [utf8hack v1.2.0](https://github.com/uyjulian/utf8hack/releases/tag/v1.2.0) から **`utf8hack.intel32.clang.7z`** を取得します。[7-Zip](https://www.7-zip.org/) などで展開し、**`utf8hack.dll`** を用意してください。本リポジトリにプラグインは同梱していません。
4. Steam でゲームを右クリック → **管理 → ローカルファイルを閲覧**。`yuusyatsuma.eXe` と `data.xp3` があるフォルダーを確認します。
5. 本リポジトリの **`Apply.cmd`** をダブルクリックします。最初のダイアログで**ゲームのフォルダー**、次のダイアログで展開した **`utf8hack.dll`** を選び、適用を確認します。ダイアログは英語です。大きなアーカイブを読むため、照合には少し時間がかかります。
6. ツールはゲームフォルダー内の **`.unicode-fix-backup`** に元のファイルを保存してから適用します。バージョンやプラグインのハッシュ不一致は警告のみです。既存のプラグインが異なる場合も、バックアップしてから置き換えます。バックアップは保管してください。
7. Steam のゲームの**プロパティ → 一般 → 起動オプション**に、別のテストコピーを起動する古いコマンドがあれば削除します。この方式では空欄で構いません。通常どおり**プレイ**を押します。

このパッチのための Windows 言語変更や再起動は不要です。ツールは自動ダウンロードやアップロードを行いません。変更するのは選択したゲームフォルダーだけです。`savedata` は変更せず、別のテストコピーのセーブデータも自動移行しません。

## 変更内容と仕組み

| ファイル | 内容 |
|---|---|
| `yuusyatsuma.eXe` | オフセット `0x2C82EA` の CP932 フォント名 `ＭＳ Ｐゴシック` を ASCII の `MS PGothic` に置換します。ゼロ埋めで元の長さを維持し、他のバイトは変更しません。 |
| `yuusyatsuma.cf` | `readencoding=Shift_JIS` を設定します。他の設定、文字コード、BOM、改行は保持します。`\xNN` はエンジンの設定構文です。 |
| `utf8hack.tpm` | 選択した上流 DLL を `.tpm` 名で配置し、スクリプトより前に読み込みます。メモリ内の文字読み込み処理を置き換え、CP932 でスクリプトを解釈します。 |

プラグインだけではスクリプト読み込み後のネイティブ Layer 初期化で再び失敗しました。フォント名の置換は、この2つ目の変換エラーへの対処です。ゲームアーカイブ、翻訳、セーブ形式、Windows のコードページは変更しません。吉里吉里 Z では別のメニュー互換性エラーが発生したため採用していません。

## 元に戻す・問題が起きた場合

- ゲームを終了して **`Restore.cmd`** を実行し、同じフォルダーを選びます。元のファイルを復元し、元々存在しなかったプラグインだけを削除します。セーブデータとバックアップは残します。
- 適用後に Steam 更新などでファイルが変わった場合、復元は上書きを拒否します。バックアップを保管して状況を確認してください。
- 復元後や失敗後に再適用する際は、既存の `.unicode-fix-backup` をゲームフォルダー外へ安全に保管してください。古いバックアップは上書きしません。
- バージョン／プラグインの SHA-256 不一致は警告のみで、適用を続けます。互換性は未検証です。CLI はコンソールに、GUI は完了時の要約にも警告を表示します。
- 修正位置のバイト列が元の状態または修正済み状態と一致しない場合は停止します。バックアップの整合性確認と復元時の競合チェックは引き続き厳格です。これはファイル保護であり、バージョン制限ではありません。
- 権限やファイルロックのエラーでは、ゲームを終了して書き込み権限を確認してください。インストール失敗時は、完了した書き込みの巻き戻しを試みます。
- Steam の更新や整合性確認は EXE や設定を元に戻すことがありますが、追加プラグインは残る場合があります。新ビルドに古いパッチを無理に適用しないでください。
- 実験的な実行時プラグインです。セキュリティ製品に阻止された場合は保護を無効化せず、警告と上流の出所を確認してください。

## コマンドラインとテスト

```text
python patch.py check --game-dir "D:\SteamLibrary\steamapps\common\To the Wives Who Were Heroes"
python patch.py apply --game-dir "D:\SteamLibrary\steamapps\common\To the Wives Who Were Heroes" --plugin "D:\Downloads\utf8hack.dll"
python patch.py restore --game-dir "D:\SteamLibrary\steamapps\common\To the Wives Who Were Heroes"
python -m unittest -v test_patch.py
```

パスは例です。実際の場所に置き換えてください。`check` はファイルを変更しません。テスト範囲と任意のローカル統合テストは [TESTING.md](TESTING.md) に記載しています。
